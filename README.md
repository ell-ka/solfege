# Solfège

Lancer le serveur : `python3 -m http.server 8080`

Ouvrir `http://localhost:8080` dans le navigateur.

## Fichiers

| Fichier | Rôle |
|---|---|
| `index.html` | Shell HTML minimal |
| `css/styles.css` | Tous les styles |
| `js/config.js` | Constantes et définitions notes |
| `js/audio.js` | Synthèse Web Audio |
| `js/staff.js` | Dessin SVG portée |
| `js/deck.js` | Répétition espacée + localStorage |
| `js/piano.js` | Clavier piano UI |
| `js/simon.js` | Mode Simon Says |
| `js/progress.js` | Barre de progression + unlock |
| `js/main.js` | Boucle principale |
